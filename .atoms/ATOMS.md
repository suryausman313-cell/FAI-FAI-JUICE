# Project Context

## Project Overview
Vita Napoli - A mobile-first restaurant ordering app for an Italian pizzeria in Murbah, Fujairah, UAE. Features customer ordering with pickup, admin dashboard with sales analytics, and full menu management.

## Key Decisions
| Date | Decision | By | Rationale |
|------|----------|-----|-----------|
| 2026-07-16 | Dark theme with red/green accents | Alex | Italian restaurant branding, modern mobile-first feel |
| 2026-07-16 | localStorage cart | Alex | No login required for browsing, simple UX |
| 2026-07-16 | Custom API for orders | Alex | Better validation and control over order flow |
| 2026-07-16 | Pickup only, no delivery | Alex | Per restaurant requirements |
| 2026-07-16 | Cash/Card on pickup payment | Alex | No online payment needed per requirements |
