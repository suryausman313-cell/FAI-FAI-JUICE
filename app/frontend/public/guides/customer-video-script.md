# 🎬 Customer App Video Tutorial Script
## Vita Napoli - Customer Ordering Guide

**Total Duration:** ~2:30 minutes  
**Language:** Urdu/English mix (casual tone)  
**Target Audience:** Customers who want to order from the app

---

## Scene 1: App Opening & Login (~15 seconds)

**Screen Action:**  
- Open the app homepage showing the Vita Napoli landing page
- Click on "Login / Sign Up" button
- Show the login screen, enter phone/email
- Complete login

**Narration:**  
"Assalam o Alaikum! Aaj hum aapko dikhayenge ke Vita Napoli app se order kaise karna hai. Sabse pehle app kholein aur Login button pe click karein. Apna phone number ya email daalein aur login ho jayein."

---

## Scene 2: Browse Menu (~20 seconds)

**Screen Action:**  
- Scroll through the menu page showing categories
- Click on different categories (Pizza, Pasta, Drinks, etc.)
- Show menu items with prices and images
- Hover over a few items to show details

**Narration:**  
"Login hone ke baad aapko menu dikhai dega. Yahan aap categories dekh sakte hain - Pizza, Pasta, Drinks wagairah. Har item ki photo, price aur description clear dikhai deti hai. Jo item pasand aaye uspe click karein."

---

## Scene 3: Customize & Add to Cart (~25 seconds)

**Screen Action:**  
- Click on a pizza item
- Show size selection (Small, Medium, Large)
- Select extras/toppings
- Adjust quantity
- Click "Add to Cart" button
- Show cart badge updating
- Add one more item to cart

**Narration:**  
"Item pe click karne ke baad size select karein - Small, Medium ya Large. Agar extra toppings chahiye toh woh bhi select karein. Quantity set karein aur 'Add to Cart' pe click karein. Dekho cart icon pe number aa gaya! Aise hi aur items add kar sakte hain."

---

## Scene 4: View Cart & Review (~15 seconds)

**Screen Action:**  
- Click on cart icon
- Show cart page with all items listed
- Show item details (size, extras, quantity, price)
- Show subtotal, service fee, and total
- Point out the "Add more to remove small order fee" hint (if applicable)

**Narration:**  
"Ab cart icon pe click karein. Yahan aapke saare items dikhai denge - size, extras, quantity sab kuch. Neeche total amount dikhai dega including service fee. Agar order chhota hai toh small order fee bhi lag sakti hai - thoda aur add karein toh hat jayegi."

---

## Scene 5: Select Order Type - Pickup (~15 seconds)

**Screen Action:**  
- Click "Checkout" button from cart
- Show checkout page
- Click on "Pickup" option (show it highlighted in red)
- Show the pickup description "Come collect your order"

**Narration:**  
"Checkout pe click karein. Ab order type select karna hai. Agar aap khud lene aayenge toh 'Pickup' select karein. Iska matlab hai aap restaurant se apna order collect karenge."

---

## Scene 6: Select Order Type - Delivery (~25 seconds)

**Screen Action:**  
- Switch to "Delivery" option
- Show the map appearing
- Click on map to select location OR click "Use My Location" button
- Show the pin dropping on map
- Show delivery zone confirmation (green checkmark with fee)
- Show delivery address notes field
- Type building/floor info

**Narration:**  
"Agar ghar pe mangwana hai toh 'Delivery' select karein. Map pe apni location select karein - ya toh map pe click karein ya 'Use My Location' button use karein. Jab pin lag jaye toh delivery fee dikhai degi. Neeche building name aur floor number likh dein taake rider ko asaani ho."

---

## Scene 7: Fill Customer Info (~15 seconds)

**Screen Action:**  
- Fill in Name field
- Fill in Phone number field
- (For pickup) Fill in Car info field
- Add any special notes/instructions

**Narration:**  
"Ab apna naam aur phone number daalein - yeh zaroori hai. Agar pickup hai toh car ki details bhi daal sakte hain taake staff ko pata chale. Koi special instruction ho toh notes mein likh dein."

---

## Scene 8: Payment Method & Place Order (~20 seconds)

**Screen Action:**  
- Show payment method options (Cash / Card)
- Select preferred payment method
- Review the order summary one more time
- Click "Place Order" button
- Show loading state
- Show order confirmation/success message

**Narration:**  
"Payment method select karein - Cash ya Card, jo bhi aapko suit kare. Order summary ek baar check kar lein - sab theek hai toh 'Place Order' pe click karein. Bas! Aapka order place ho gaya! Ab restaurant ko notification chali gayi hai aur woh aapka order tayyar karenge."

---

## Scene 9: Deals Page (Bonus) (~15 seconds)

**Screen Action:**  
- Go back to homepage
- Click on "Deals" section
- Show available deals with prices
- Click on a deal, select items per category
- Add deal to cart

**Narration:**  
"Ek aur cheez - Deals page pe jaayein toh special offers milenge! Deal select karein, har category se items chunein, aur cart mein add karein. Deals mein aapko zyada items kam price pe milte hain."

---

## Scene 10: Promo Code (Bonus) (~10 seconds)

**Screen Action:**  
- In checkout, show promo code field
- Type a promo code
- Click "Apply"
- Show discount applied to total

**Narration:**  
"Agar aapke paas promo code hai toh checkout mein daal ke Apply karein - discount lag jayega! Enjoy karein apna order!"

---

## Closing (~5 seconds)

**Narration:**  
"Toh yeh tha Vita Napoli app ka complete guide. Order karein, enjoy karein! Shukriya!"

---

### 📝 Recording Tips:
- Use phone screen recording for authentic mobile feel
- Keep movements slow so viewers can follow
- Highlight buttons with a brief pause before clicking
- Use a quiet environment for narration
- Add background Italian music at low volume
