# 🎬 Admin Panel Video Tutorial Script
## Vita Napoli - Admin/Owner Guide

**Total Duration:** ~3:00 minutes  
**Language:** Urdu/English mix (casual tone)  
**Target Audience:** Restaurant owner/staff managing orders

---

## Scene 1: Admin Login (~10 seconds)

**Screen Action:**  
- Open the app and navigate to /admin
- Show admin login page
- Enter admin credentials
- Login successfully to dashboard

**Narration:**  
"Assalam o Alaikum! Yeh hai Vita Napoli ka Admin Panel guide. Sabse pehle /admin pe jaayein aur apne credentials se login karein."

---

## Scene 2: Dashboard Overview (~15 seconds)

**Screen Action:**  
- Show the admin dashboard
- Point out key sections: Today's Orders count, Revenue, Pending orders
- Show navigation sidebar with all options (Orders, Menu, Deals, Sales, Settings)

**Narration:**  
"Yeh hai aapka dashboard. Yahan aaj ke orders, revenue, aur pending orders sab ek nazar mein dikhai dete hain. Left side mein navigation hai - Orders, Menu, Deals, Sales Report, aur Settings."

---

## Scene 3: New Order Arrives (~15 seconds)

**Screen Action:**  
- Go to Orders page
- Show a new order appearing with "Pending" status (yellow badge)
- Click on the order to expand details
- Show order items, customer name, phone, order type, payment method, total

**Narration:**  
"Jab customer order place karta hai toh yahan 'Pending' status mein dikhai deta hai. Order pe click karein toh poori details aayengi - kya order kiya, customer ka naam, phone number, pickup ya delivery, payment method, sab kuch."

---

## Scene 4: Accept a Pickup Order (~20 seconds)

**Screen Action:**  
- Click "Accept" button on a Pickup order
- Show status change to "Accepted" (blue badge)
- Show the order timeline/status updating
- Click "Mark as Preparing" or next status
- Click "Mark as Ready for Pickup"
- Show final status "Ready" (green badge)

**Narration:**  
"Pickup order accept karne ke liye 'Accept' button dabayein. Status 'Accepted' ho jayega. Jab order banana shuru karein toh 'Preparing' mark karein. Jab order tayyar ho jaye toh 'Ready for Pickup' mark karein. Customer ko notification mil jayegi ke order ready hai."

---

## Scene 5: Accept a Delivery Order (~20 seconds)

**Screen Action:**  
- Show a Delivery order in pending
- Click "Accept" button
- Show status change to "Accepted"
- Show delivery details: customer location on map, delivery address, delivery fee
- Click "Mark as Preparing"

**Narration:**  
"Delivery order bhi aise hi accept karein. Delivery order mein customer ki location map pe dikhai degi, address notes bhi honge. Accept karein aur preparing mark karein jab banana shuru karein."

---

## Scene 6: Assign Rider for Delivery (~25 seconds)

**Screen Action:**  
- On the delivery order, show "Assign Rider" section
- Show list of available riders
- Select a rider from the dropdown/list
- Click "Assign" button
- Show rider assigned confirmation
- Show rider's name appearing on the order

**Narration:**  
"Delivery order ke liye rider assign karna zaroori hai. 'Assign Rider' section mein available riders ki list aayegi. Rider select karein aur Assign pe click karein. Ab rider ko notification mil jayegi ke order pick karna hai."

---

## Scene 7: Delivery Order Flow - Picked Up & Delivered (~20 seconds)

**Screen Action:**  
- Show order with rider assigned
- Click "Mark as Picked Up" (rider has collected the order)
- Show status change
- Click "Mark as Delivered" (order reached customer)
- Show final "Delivered" status (green badge)
- Show order moving to completed section

**Narration:**  
"Jab rider order le ke nikle toh 'Picked Up' mark karein. Jab customer ko mil jaye toh 'Delivered' mark karein. Order complete ho gaya! Yeh automatically completed orders mein chala jayega."

---

## Scene 8: Pickup Order - Prepaid Flow (~15 seconds)

**Screen Action:**  
- Show a pickup order with Card payment
- Accept the order
- Click "Mark as Prepaid" (payment received)
- Show prepaid badge appearing
- Mark as Ready for Pickup

**Narration:**  
"Agar customer ne card se pay kiya hai toh 'Prepaid' mark karein jab payment confirm ho. Phir normally ready mark karein. Cash orders mein pickup ke waqt payment lein."

---

## Scene 9: Menu Management (~20 seconds)

**Screen Action:**  
- Navigate to Menu section
- Show list of menu items with categories
- Click "Add Item" or edit an existing item
- Show form: name, price, category, sizes, extras, image
- Save the item
- Show item appearing in the menu

**Narration:**  
"Menu manage karne ke liye Menu section mein jaayein. Yahan items add, edit ya delete kar sakte hain. Naya item add karne ke liye naam, price, category, sizes aur extras set karein. Image upload karein aur save karein."

---

## Scene 10: Deal Builder (~15 seconds)

**Screen Action:**  
- Navigate to Deals section
- Show existing deals
- Click "Create New Deal"
- Set deal name, price, add categories
- Set items per category
- Save deal and show it active

**Narration:**  
"Deals section mein special offers bana sakte hain. Deal ka naam, price set karein, categories add karein jaise '2 Pizza chunein', '1 Drink chunein'. Save karein aur deal customer app pe live ho jayegi."

---

## Scene 11: Sales Report (~15 seconds)

**Screen Action:**  
- Navigate to Sales section
- Show revenue breakdown: Today, This Week, This Month
- Show payment breakdown (Cash vs Card)
- Show service fee and small order fee collected
- Switch between time periods

**Narration:**  
"Sales Report mein poora revenue breakdown milega - aaj ka, is hafte ka, mahine ka. Cash aur Card ka alag alag dikhai deta hai. Service fee aur small order fee bhi track hoti hai."

---

## Scene 12: Settings (~20 seconds)

**Screen Action:**  
- Navigate to Settings
- Show Restaurant Info section (name, phone, hours)
- Show Delivery Settings (zones, charges, radius)
- Show Payment Methods toggles (Cash/Card for Pickup/Delivery)
- Show Fee Settings (Service fee, Small order fee)
- Save settings

**Narration:**  
"Settings mein restaurant ki info update karein, delivery zones set karein, payment methods ON/OFF karein - Cash ya Card, Pickup ya Delivery ke liye alag alag. Service fee aur small order fee bhi yahan se control hoti hai. Changes save karein aur customer app mein turant update ho jayega."

---

## Scene 13: Rider Management (~10 seconds)

**Screen Action:**  
- Show Riders section
- Add a new rider (name, phone)
- Show rider appearing in list
- Show rider available for assignment on delivery orders

**Narration:**  
"Riders section mein delivery riders add karein - naam aur phone number daalein. Yeh riders phir delivery orders pe assign karne ke liye available honge."

---

## Closing (~5 seconds)

**Narration:**  
"Toh yeh tha Admin Panel ka complete guide. Apne restaurant ko efficiently manage karein! Koi sawal ho toh contact karein. Shukriya!"

---

### 📝 Recording Tips:
- Use desktop/tablet for admin panel recording (wider screen shows more)
- Have some test orders ready before recording
- Create a test pickup order AND a test delivery order beforehand
- Keep a rider added so you can demonstrate assignment
- Pause briefly on each status change so viewers can see the transition
- Use screen zoom/highlight for important buttons
- Add subtle background music
- Consider split-screen: admin panel + customer phone for order flow
