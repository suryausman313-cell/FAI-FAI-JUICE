# Project Summary
Vita Napoli Pizza is a mobile-first restaurant ordering application tailored for an Italian pizzeria in Murbah, Fujairah, UAE. It aims to enhance customer engagement by allowing users to browse the menu, customize orders, and select pickup or delivery options. Key features include an admin dashboard for order management, sales analysis, and customer interaction tracking. Recent updates have improved the "My Location" functionality, ensuring accurate GPS pin placement and automatic recalculation of delivery charges, further enhancing the user experience.

# Project Module Description
The project includes the following functional modules:
- **Customer Pages**: Interfaces for menu browsing, cart management, and order placement with mobile number authentication via OTP.
- **Admin Pages**: Interfaces for order management, customer oversight, and menu management, including:
  - **Admin Permissions**: Role-based access for new admins.
  - **Delivery Zones Management**: Admins can create and manage delivery zones with variable charges based on distance.
  - **Customer Tips**: Customers can add tips during checkout, displayed separately in the admin panel and rider app.
  - **Order Status Flow**: New orders start with a "pending" status, changing only through admin or kitchen actions.
- **Kitchen Orders**: Real-time interface for kitchen staff to manage orders with notifications for new pickups and deliveries.
- **Backend APIs**: Endpoints for order placement, menu management, and admin functionalities.
- **Sales Reports**: Analytics on sales, including service and small order fees, with improved accuracy excluding cancelled orders.
- **Offers & Promotions**: Management of promotional offers with a dynamic Deal Builder.
- **Customer Feedback**: Interface for customers to rate and comment on their experiences.
- **Delivery Management**: Configuration of delivery options, charges, and estimated times by admins.
- **Rider Panel**: Management interface for delivery riders with real-time updates and earnings tracking.
- **Language Management**: Admin functionality to manage available languages.
- **Notifications**: Creation and management of customer notifications.
- **Payment Methods Control**: Admins can toggle payment methods.
- **Service Fee Configuration**: Admins can set service fees for various order types.
- **Activity Logs**: Tracking of admin actions for accountability.
- **Admin Accounts Management**: Management of sub-admin accounts with adjustable permissions.
- **Blog Visibility Control**: Admin can toggle the display of the blog section.
- **Checkout Flow Control**: Admins can choose between a two-step or direct checkout process.
- **Customer Management Panel**: Admin section showing all registered customers with detailed statistics.
- **Rider Management System**: Dashboard for riders, including delivery tracking and performance metrics.

# File Description Inventory
- **backend/routers/admin.py**: API routes for admin functionalities, including customer management.
- **backend/routers/admin_enhanced.py**: Enhanced API routes for order deletion, activity logs, feedback replies, and selective data reset features.
- **backend/routers/menu_items.py**: Manages menu items.
- **backend/routers/restaurant_settings.py**: Manages restaurant settings.
- **backend/routers/orders.py**: Handles customer order placement and history, updated to include tip fields and delivery charge validation.
- **backend/routers/rider.py**: API routes for managing delivery riders.
- **backend/routers/offers.py**: Manages promotional offers.
- **backend/routers/deals.py**: Manages admin deals.
- **backend/routers/deals_public.py**: Public API for accessing active deals.
- **backend/routers/delivery_zones.py**: Manages delivery zones and calculations, now with gap-tolerant matching logic.
- **backend/models/customer_sessions.py**: Model for tracking customer online sessions.
- **backend/models/delivery_zones.py**: Model for delivery zones with distance and charge attributes.
- **backend/models/orders.py**: Model for orders, updated to include tip fields and delivery charge validation.
- **frontend/src/pages/**: Main application pages including checkout and admin functionalities.
- **frontend/src/components/**: Reusable UI components.
- **frontend/src/lib/**: Utility functions for API calls.
- **frontend/src/lib/cart-store.ts**: Manages cart state.
- **frontend/src/pages/admin/AdminSales.tsx**: Admin sales management page with tips reporting functionality.
- **frontend/src/pages/Checkout.tsx**: Customer checkout page updated to include tipping options and validation for delivery charges.
- **frontend/src/pages/RiderPanel.tsx**: Rider management dashboard updated to show delivery earnings and tips.

# Technology Stack
- **Frontend**: React, TypeScript, Vite, Tailwind CSS
- **Backend**: FastAPI, PostgreSQL
- **SDK**: @metagptx/web-sdk for authentication and API calls

# Usage
To set up the project:
1. Install dependencies:
   - Navigate to the backend and frontend directories and run:
     ```bash
     pnpm install
     ```
2. Build the project:
   - For the frontend, run:
     ```bash
     pnpm run build
     ```
3. Start the backend server:
   - Use the command:
     ```bash
     python main.py
     ```
